# ♻️ SmartWaste AI

**Smart Urban Waste Management & Community Infrastructure Tracking Platform**

SmartWaste AI is a web application designed to empower citizens and municipal administrations to efficiently report, track, prioritize, and resolve urban waste, environmental, and infrastructure issues.

## 🌟 Key Features

### 👤 Citizen Portal
- **AI Category Detection**: Automated categorization of reported issues (Water Leakage, Illegal Dumping, Pothole, Overflowing Bin, Street Waste, Other) based on image inspection.
- **Smart Priority Scoring**: Dynamic priority score (0-100) and urgency levels (Low, Medium, High) calculated from location type, population impact, and community upvotes.
- **Interactive Map Integration**: Precise geographic tagging using Leaflet interactive maps.
- **Status & Resolution Tracking**: Real-time progress monitoring from *Pending* ➔ *Assigned* ➔ *In Progress* ➔ *Resolved*, featuring verification with **Before & After** comparison images.
- **Gamification & Leaderboard**: Earn **EcoPoints** and unlock achievement badges by reporting verified issues and upvoting community reports.
- **Notification System**: Notifications for report submission, assignment, resolution, and milestone upvotes.

### 🛡️ Admin Dashboard
- **Real-Time Analytics**: Visual breakdown of total reports, resolution rates per category, peak reporting times, and issue status distributions powered by Chart.js.
- **Hotspot Map Identification**: Highlight areas with high concentrations of unresolved urban issues.
- **Report Management**: Filter, search, assign cleanup teams (e.g., *Sanitation Team A*, *Water Dept*, *PWD*), update statuses, and upload resolution proof images.
- **Automated Notifications**: Broadcast status updates to citizens upon administrative changes.

## 🛠️ Technology Stack

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/) & [React 19](https://react.dev/)
- **Styling**: Modern Vanilla CSS, Glassmorphism, Responsive Grid & Flexbox
- **Icons & Charts**: [Lucide React](https://lucide.dev/), [Chart.js](https://www.chartjs.org/) & [React-ChartJS-2](https://react-chartjs-2.js.org/)

- **Database**: [Supabase PostgreSQL](https://supabase.com/) *(with local SQLite fallback)*
- **Storage**: [Supabase Storage](https://supabase.com/storage) *(with local `/public/uploads` fallback)*

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v18.0.0 or higher)
- npm or yarn

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/SUP-18/SMART-WASTE-AI.git

# Navigate into the project directory
cd SMART-WASTE-AI

# Install dependencies
npm install
```

### 3. Local Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## ☁️ Supabase Cloud & Vercel Deployment Setup

### Environment Variables
Create a `.env.local` file in the project root:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-supabase-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
```

### Database Schema (Supabase SQL Editor)
Run the following script in your Supabase SQL Editor:

```sql
CREATE TABLE IF NOT EXISTS users (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  email TEXT UNIQUE NOT NULL,
  password TEXT NOT NULL,
  role TEXT DEFAULT 'citizen',
  ecoPoints INTEGER DEFAULT 0,
  badges TEXT DEFAULT '[]',
  createdAt TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS reports (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  reportId TEXT UNIQUE NOT NULL,
  userId BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  category TEXT NOT NULL,
  description TEXT,
  imageUrl TEXT,
  afterImageUrl TEXT,
  latitude DOUBLE PRECISION,
  longitude DOUBLE PRECISION,
  locationText TEXT,
  priorityScore INTEGER DEFAULT 50,
  priorityLevel TEXT DEFAULT 'Medium',
  peopleAffected TEXT DEFAULT '1-5',
  locationType TEXT DEFAULT 'Public Road',
  status TEXT DEFAULT 'Pending',
  assignedTo TEXT,
  upvoteCount INTEGER DEFAULT 0,
  aiConfidence DOUBLE PRECISION DEFAULT 0.85,
  resolvedAt TIMESTAMPTZ,
  createdAt TIMESTAMPTZ DEFAULT NOW(),
  updatedAt TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS notifications (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  userId BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  message TEXT NOT NULL,
  type TEXT DEFAULT 'info',
  reportId TEXT,
  read INTEGER DEFAULT 0,
  createdAt TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS upvotes (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  reportId BIGINT NOT NULL REFERENCES reports(id) ON DELETE CASCADE,
  userId BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  createdAt TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(reportId, userId)
);
```

### Seed Demo Accounts (Supabase SQL Editor)
After creating the tables above, run this to insert the demo accounts:

```sql
-- Admin account
INSERT INTO users (name, email, password, role, ecopoints)
VALUES ('SmartWaste Admin', 'admin@smartwasteai.com', 'admin123', 'admin', 0)
```

### Storage Bucket Setup
1. In Supabase Dashboard, go to **Storage**.
2. Create a bucket named **`reports`**.
3. Toggle **Public Bucket** to `ON`.
